# Put the IQVIA file here

Download the IQVIA National Medical and Treatment Audit (NMTA) file from Canvas and put the `.csv` file in this
folder. Keep exactly one `.csv` file here.

The IQVIA data is licensed for this course only:

- Never commit it, upload it, or share it outside the course. The repository's `.gitignore` keeps everything in this
  folder except this README out of Git.
- Delete it from your computer when the course ends.

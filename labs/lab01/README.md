# Lab 1: Preparation videos

Every part of the HealthRiskAI pipeline runs as a container, so Lab 1 gets you comfortable with Docker and Docker
Compose before you install anything.

## Watch

1. **Docker Compose Tutorial – Docker in Practice** (TechWorld with Nana)
   <https://www.youtube.com/watch?v=MVIcrmeV_6c>
   How a multi-container app is defined in one compose file: services, networks, environment variables, and
   volumes. This matches how our pipeline's components run together. Watch it in full.

2. **Docker Compose in 12 Minutes** (Jake Wright)
   <https://www.youtube.com/watch?v=Qw9zlE3t8Ko>
   A short refresher on the core commands (`up`, `down`, `ps`, `logs`). Good to rewatch right before Lab 2.

> These are third-party videos and may use different tool versions than this course. When they differ, follow the
> commands in the lab instructions.
